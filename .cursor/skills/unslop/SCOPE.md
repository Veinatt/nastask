# NasTask scope for unslop

Credit: unslop by Damir Sokolovsky ([@heydamir](https://x.com/heydamir)), [heydamir/unslop](https://github.com/heydamir/unslop), CC BY 4.0.

## In scope

- Tabs: Home, Stats, Reports, Settings
- Chrome: Navigation, AppLayout, SplashScreen, sync status
- Interval cards/dialogs, stats/reports widgets, UI primitives
- `frontend/src/index.css` and theme tokens (light / dark / cozy)

## Out of scope

- NasTale / memory quiz (`frontend/src/pages/memory/**`, `components/memory/**`, `memory/**`)
- `froggy/**` and postcard iframe on Home (do not redesign froggy)

Do not change product features, interval logic, or bot behavior — visual craft only.
